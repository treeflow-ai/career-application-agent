# Document Quality

Application documents must be readable, ATS-safe, truthful, internally consistent, and link-safe.

For generated DOCX/PDF, visible email/GitHub/project links must be actual hyperlinks, not text that merely resembles a URL. Email uses `mailto:`; web links use explicit `https://` targets.

Do not solve pagination by deleting high-value verified evidence before trying concise wording, duplicate removal, and layout balancing.
