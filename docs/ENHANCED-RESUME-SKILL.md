# Enhanced Resume Skill

This project treats resume generation as a constrained evidence-composition problem, not free-form rewriting.

## Capabilities

1. **JD decomposition before drafting** — separate must-haves, preferences, responsibilities, constraints, and named tools.
2. **Evidence map first** — every substantive candidate claim is grounded before prose generation.
3. **DIRECT / TRANSFERABLE / UNKNOWN / UNMET mapping** — prevents adjacent experience from being silently upgraded.
4. **Chronology preservation** — tailoring must not create misleading/unexplained timeline gaps merely to save space.
5. **Customer-facing evidence preservation** — retain user interviews, workflow discovery, field observation, training, deployment, support, and adoption work when relevant.
6. **Named-tool discipline** — JD keywords are not permission to add unsupported technologies.
7. **Metric discipline** — no estimated impact numbers, years, team sizes, or percentages.
8. **Evidence budgeting** — spend limited resume space on the strongest job-matched evidence while preserving coherent career history.
9. **Two-page balance** — for experienced candidates, optimize content density before shrinking typography or deleting strong evidence.
10. **Duplicate suppression** — remove repeated achievements/metrics before pagination changes.
11. **Project proof adjacency** — repository/demo/architecture/walkthrough links stay with the project they prove.
12. **Hyperlink integrity** — final document links must be real `mailto:` / `https://` relationships/annotations, not visually styled text.
13. **Cross-artifact consistency** — resume, cover letter, form answers, notes, and provenance must agree.
14. **Deterministic + semantic QA** — code catches structural/referential/privacy/link errors; model review catches scope inflation, chronology distortion, unsupported ownership, and misleading framing.

## Why this matters

The strongest optimization is not maximum keyword density. It is the strongest truthful, reviewable representation of verified evidence for a specific role.
